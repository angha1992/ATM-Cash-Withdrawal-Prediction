# 🏧 ATM Cash Withdrawal Prediction

## 📌 Overview

This project uses an Artificial Neural Network (ANN) regression model to predict ATM cash withdrawal amounts using historical transaction data and temporal features.

## 🎯 Objective

To build a regression model that can predict the total amount withdrawn from an ATM based on historical withdrawal patterns and relevant transaction features.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras
- Artificial Neural Network (ANN)
- Regression

## 🔄 Machine Learning Workflow

2. Data Understanding
3. Exploratory Data Analysis
4. Feature Engineering
5. Data Preprocessing
6. Train-Test Split
7. Feature Scaling
8. ANN Model Development
9. Model Training
10. Model Evaluation
11. Actual vs Predicted Analysis

## 📊 Model Evaluation

The model is evaluated using:

- MAE — Mean Absolute Error
- MSE — Mean Squared Error
- RMSE — Root Mean Squared Error
- R² Score

The current model achieved an R² score of approximately **0.30**, indicating scope for further improvement.

## 📈 Visualization

The project includes an Actual vs Predicted visualization to analyze the model's prediction performance.
